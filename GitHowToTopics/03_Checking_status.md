\# Temat 3 – Checking the status of the repository



\## Cel

Nauczyć się sprawdzać status repozytorium Git.



\## Kroki wykonane

Sprawdzamy aktualny stan repozytorium poleceniem:

git status

s

Wynik powinien wyglądać tak:

On branch main

nothing to commit, working tree clean



Jeżeli pojawi się On branch master zamiast On branch main, zmieniamy nazwę gałęzi poleceniem:

git branch -m master main



Polecenie git status pokazuje, że nie ma żadnych zmian do zatwierdzenia i repozytorium przechowuje aktualny stan katalogu roboczego.



Tworzymy plik dokumentacji dla tego tematu poleceniem:

touch 03\_Checking\_status.md



Do pliku wklejamy treść zadania oraz wynik polecenia git status.
