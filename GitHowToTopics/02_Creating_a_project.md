\# 2. Creating a project



\## Goals

Learn how to create a Git repository from scratch.



\### 01 Create a “Hello, World!” page

Get started in an empty directory and add an empty subdirectory named work, then create a hello.html file in it.



Run:

mkdir work

cd work

touch hello.html



File: hello.html

Hello, World!



\### 02 Create a repository

Run git init in order to create a Git repo from that directory.



Run:

git init



\### 03 Add the page to the repository

Add the “Hello, World” page to the repository.



Run:

git add hello.html

git commit -m "Initial commit"
