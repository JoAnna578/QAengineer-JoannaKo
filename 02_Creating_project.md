\# Temat 2 – Creating a project



\## Cel

Nauczyć się tworzyć repozytorium Git od podstaw.



\## Kroki wykonane



\### 1. Utworzono folder `work` i plik `hello.html`

```bash

mkdir work

cd work

touch hello.html

```

Plik `hello.html` zawiera:

```

Hello, World!

```



\### 2. Inicjalizacja repozytorium

```bash

git init

```



\### 3. Dodanie pliku do repo i pierwszy commit

```bash

git add hello.html

git commit -m "Initial commit"

```



\## Zrzuty ekranów

\- Pokazują utworzenie folderu, pliku, wynik `git init` i wynik commita.
